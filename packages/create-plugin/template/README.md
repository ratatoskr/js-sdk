# __TITLE__

A Wraith plugin in __LANGUAGE__.

```
npm install
npm run dev
```

- `npm run dev` builds into `dist/` and again on every change. Run `wraith dev add dist` once so Wraith loads it from there.
- `npm run build` type checks and builds once.
- `npm run pack` makes a zip to share or upload to the [Wraith Hub](https://hub.wraith.io).
- `npm run types` refreshes the typings in `.wraith/types` after updating Wraith.

What it can do is in [the docs](https://docs.wraith.io/plugins/js/setup/).
